## 1. Таблица выборки 2×2

Выбираем $k$ объектов из $n$ различимых объектов.

|  | **упорядоченно** | **неупорядоченно** |
|---|---|---|
| **с возвращением** | $n^k$ | $\dbinom{n+k-1}{k}$ |
| **без возвращения** | $n(n-1)\cdots(n-k+1)=\dfrac{n!}{(n-k)!}$ | $\dbinom{n}{k}$ |

Три лёгкие клетки:

- **упорядоченно, с возвращением.** На каждом из $k$ шагов независимо $n$ вариантов — правило умножения даёт $n^k$.
- **упорядоченно, без возвращения.** На шаге $j$ остаются $n-j+1$ вариант — $n(n-1)\cdots(n-k+1)$. Требуется $k\le n$.
- **неупорядоченно, без возвращения.** Каждое неупорядоченное $k$-подмножество соответствует ровно $k!$ упорядоченным выборкам (все элементы различны, значит все $k!$ перестановок дают разные упорядоченные списки и все они допустимы). Делим:
  $$\binom{n}{k}=\frac{n(n-1)\cdots(n-k+1)}{k!}=\frac{n!}{k!\,(n-k)!}.$$

### Почему четвёртая клетка тяжёлая

Тот же трюк «поделить на $k!$» здесь **не работает**. При выборе с возвращением у одного неупорядоченного результата разное число упорядоченных прообразов: набор $\{1,2,3\}$ даёт $3!=6$ упорядоченных списков, а набор $\{1,1,2\}$ — только $3$. Делить на константу нечего. Нужен другой биективный аргумент.

### Вывод: звёзды и полоски

**Шаг 1. Переформулировка.** Неупорядоченная выборка с возвращением — это не список, а *мультимножество*: важно только, сколько раз взят каждый объект. Значит результат полностью описывается вектором кратностей
$$(x_1,x_2,\dots,x_n),\qquad x_i\ge 0,\qquad x_1+x_2+\cdots+x_n=k,$$
где $x_i$ — сколько раз выбран объект $i$. Задача сведётся к подсчёту неотрицательных целочисленных решений этого уравнения.

**Шаг 2. Кодировка.** Напишем $k$ звёздочек подряд и разделим их $n-1$ вертикальной полоской на $n$ участков — по участку на каждый объект, слева направо. Число звёздочек в $i$-м участке и есть $x_i$. Например, $n=4$, $k=6$:

```
**|*||***      →  x = (2, 1, 0, 3)
||****|**      →  x = (0, 0, 4, 2)
```

Пустые участки допустимы (соседние полоски или полоска с края) — это ровно случай $x_i=0$, который нам и нужен.

**Шаг 3. Биекция.** Отображение «строка из звёзд и полосок → вектор $x$» взаимно однозначно:
- по любой строке из $k$ звёзд и $n-1$ полоски однозначно считается вектор кратностей, сумма координат которого равна числу звёзд, то есть $k$;
- обратно, по любому вектору $x$ с $\sum x_i=k$ строка восстанавливается однозначно: пишем $x_1$ звёзд, полоску, $x_2$ звезды, полоску, …

**Шаг 4. Подсчёт строк.** Строка — это последовательность из $k+(n-1)$ позиций, в которых надо выбрать, какие $k$ заняты звёздами (остальные автоматически полоски). Это уже *неупорядоченный выбор без возвращения* из третьей клетки:
$$\boxed{\ \binom{n+k-1}{k}=\binom{n+k-1}{n-1}\ }$$

**Проверка на малом случае.** $n=3$, $k=2$: формула даёт $\binom{4}{2}=6$. Руками: $\{1,1\},\{2,2\},\{3,3\},\{1,2\},\{1,3\},\{2,3\}$ — ровно 6. ✓
И заметим, что $6\ne 3^2/2!$ — ещё одно подтверждение, что деление на $k!$ здесь ложный путь.

## 2. Формула включения-исключения

$$P\left(\bigcup_{i=1}^{n} A_i\right)=\sum_{i}P(A_i)-\sum_{i<j}P(A_i\cap A_j)+\sum_{i<j<l}P(A_i\cap A_j\cap A_l)-\cdots+(-1)^{n+1}P(A_1\cap\cdots\cap A_n).$$

Компактно:
$$P\left(\bigcup_{i=1}^{n} A_i\right)=\sum_{j=1}^{n}(-1)^{j+1}\sum_{|S|=j}P\!\left(\bigcap_{i\in S}A_i\right).$$

**Вывод через индикаторы.** Возьмём произвольный исход $\omega\in\bigcup A_i$ и пусть он лежит ровно в $m\ge 1$ из событий $A_i$. Сколько раз он учтён в правой части? В сумме по $j$-кратным пересечениям он попадает в те $\binom{m}{j}$ наборов $S$, которые целиком состоят из «его» событий. Итого его суммарный вес равен
$$\sum_{j=1}^{m}(-1)^{j+1}\binom{m}{j}=-\sum_{j=1}^{m}(-1)^{j}\binom{m}{j}=-\left[(1-1)^m-\binom{m}{0}\right]=1.$$
Каждый исход из объединения учтён с весом ровно 1, каждый исход вне объединения — с весом 0. Значит правая часть считает $P(\bigcup A_i)$. $\blacksquare$

**Симметричный частный случай.** Если все $j$-кратные пересечения равновероятны (это бывает почти всегда в задачах ниже), то
$$P\left(\bigcup_{i=1}^{n} A_i\right)=\sum_{j=1}^{n}(-1)^{j+1}\binom{n}{j}\,p_j,\qquad p_j=P(A_1\cap\cdots\cap A_j).$$

Это рабочая форма для задач 47 и 48.

## 3. Десять задач

### Задача 1. Перестановки букв в MISSISSIPPI

11 букв: M×1, I×4, S×4, P×2. Перестановки мультимножества:
$$\frac{11!}{1!\,4!\,4!\,2!}=\frac{39\,916\,800}{1\cdot 24\cdot 24\cdot 2}=\boxed{34\,650}.$$

*Почему так:* если бы все буквы были различимы, ответ был бы $11!$; но любая из $4!$ перестановок между собой четырёх I даёт то же слово, аналогично для S и P — делим на $4!\,4!\,2!$.

### Задача 2. Телефонные номера

**(a)** Первая цифра: 8 вариантов (от 2 до 9), остальные шесть: по 10.
$$8\cdot 10^6=\boxed{8\,000\,000}.$$

**(b)** Считаем дополнение внутри уже полученного множества. Номеров, начинающихся на 911: первые три цифры зафиксированы (9 — допустимая первая цифра), остальные четыре свободны — $10^4=10\,000$ штук. Тогда
$$8\,000\,000-10\,000=\boxed{7\,990\,000}.$$

### Задача 3. Ужины Фреда

**(a)** Упорядоченная выборка без возвращения (порядок = дни недели), $k=5$ из $n=10$:
$$10\cdot 9\cdot 8\cdot 7\cdot 6=\boxed{30\,240}.$$

**(b)** Понедельник: 10 вариантов. Каждый следующий день: любой ресторан, кроме вчерашнего, то есть 9 вариантов, независимо от предыстории.
$$10\cdot 9^4=10\cdot 6561=\boxed{65\,610}.$$

### Задача 4. Круговой турнир, $n$ игроков

**(b)** Каждая пара играет ровно раз, значит игр
$$\binom{n}{2}=\frac{n(n-1)}{2}.$$

**(a)** Исход турнира — назначение победителя в каждой игре, независимо, 2 варианта на игру:

### Задача 15. Story proof: $\sum_{k=0}^{n}\binom{n}{k}=2^n$

*(в тексте задача пришла обрезанной; это стандартная формулировка §1.9)*

**История.** Пусть клуб из $n$ человек. Считаем двумя способами число возможных подкомитетов (любого размера, включая пустой и полный).

- **Способ 1.** Обходим людей по одному и для каждого решаем «в комитете / не в комитете»: $2$ варианта на человека, независимо — всего $2^n$ подкомитетов.
- **Способ 2.** Сгруппируем подкомитеты по размеру. Комитетов ровно из $k$ человек — $\binom{n}{k}$ штук (неупорядоченный выбор без возвращения), $k$ пробегает $0,1,\dots,n$. Суммируем по $k$: $\sum_{k=0}^{n}\binom{n}{k}$.

Оба способа считают одно и то же конечное множество, значит числа равны. $\blacksquare$

*(Другой факт: это биномиальная теорема $(1+1)^n=\sum\binom{n}{k}1^k1^{n-k}$, но история объясняет, почему.)*

### Задача 16. $\binom{n}{k}+\binom{n}{k-1}=\binom{n+1}{k}$ (правило Паскаля)

**(a) Алгебраически.** Для $1\le k\le n$:
$$\binom{n}{k}+\binom{n}{k-1}=\frac{n!}{k!\,(n-k)!}+\frac{n!}{(k-1)!\,(n-k+1)!}.$$
Приводим к общему знаменателю $k!\,(n-k+1)!$: первую дробь домножаем на $(n-k+1)$, вторую на $k$:
$$=\frac{n!\,(n-k+1)+n!\,k}{k!\,(n-k+1)!}=\frac{n!\,(n+1)}{k!\,(n+1-k)!}=\frac{(n+1)!}{k!\,(n+1-k)!}=\binom{n+1}{k}.$$

**(b) Историей.** Пусть $n+1$ человек, один из них заранее назначен **президентом**. Выбираем комитет из $k$ человек — правая часть, $\binom{n+1}{k}$.

Разобьём все такие комитеты на два непересекающихся класса:

- президент **не входит** в комитет: тогда все $k$ членов выбираются из оставшихся $n$ человек — $\binom{n}{k}$ способов;
- президент **входит** в комитет: остальные $k-1$ мест заполняются из оставшихся $n$ человек — $\binom{n}{k-1}$ способов.

Классы не пересекаются и покрывают всё, значит $\binom{n+1}{k}=\binom{n}{k}+\binom{n}{k-1}$. $\blacksquare$

### Задача 21. Лифт и три подряд идущих этажа

Каждый из трёх пассажиров независимо и равновероятно хочет один из этажей $2,\dots,10$ (9 этажей). Всего исходов $9^3=729$.

Нажатыми оказываются кнопки *различных* желаемых этажей. Пассажиров трое, значит «нажаты кнопки трёх подряд идущих этажей» ⟺ все три желаемых этажа различны и образуют блок из трёх последовательных чисел.

- Блоков вида $\{f,f+1,f+2\}$ внутри $\{2,\dots,10\}$: $f=2,\dots,8$ — **7** штук.
- Каждому блоку соответствует $3!=6$ распределений «кто какой этаж хочет».

$$P=\frac{7\cdot 6}{729}=\frac{42}{729}=\boxed{\frac{14}{243}}\approx 0.0576.$$

### Задача 22. Трое старших детей — девочки

6 детей: 3 мальчика и 3 девочки, все порядки рождения равновероятны. Рассмотрим позиции трёх девочек как случайное $3$-подмножество из $6$ мест — все $\binom{6}{3}=20$ подмножеств равновероятны. Благоприятно ровно одно (три старших места).
$$P=\frac{1}{\binom{6}{3}}=\boxed{\frac{1}{20}}=0.05.$$

*Альтернативно через порядки:* $\dfrac{3!\cdot 3!}{6!/(3!\,3!)\cdot\ldots}$ — но подход «позиции девочек» короче и не требует решать, различимы ли дети.

### Задача 47. Игральная кость: чтобы одно значение не выпало

Кость бросают $n$ раз. Пусть $A_i$ — «значение $i$ ни разу не появилось», $i=1,\dots,6$.

Для набора $S$ из $j$ значений: $\bigcap_{i\in S}A_i$ означает, что все $n$ бросков попали в оставшиеся $6-j$ граней, значит
$$P\!\left(\bigcap_{i\in S}A_i\right)=\left(\frac{6-j}{6}\right)^{n},$$
и это зависит только от $j$. По включению-исключению (симметричная форма):
$$P\left(\bigcup_{i=1}^{6}A_i\right)=\sum_{j=1}^{5}(-1)^{j+1}\binom{6}{j}\left(\frac{6-j}{6}\right)^{n}$$
$$=6\left(\frac{5}{6}\right)^{n}-15\left(\frac{4}{6}\right)^{n}+20\left(\frac{3}{6}\right)^{n}-15\left(\frac{2}{6}\right)^{n}+6\left(\frac{1}{6}\right)^{n}.$$

Слагаемое $j=6$ опущено: оно равно $\binom{6}{6}\cdot 0^n=0$ при $n\ge 1$ (все шесть значений не могут отсутствовать одновременно).

**Проверки.** $n=1$: $6\cdot\frac56-15\cdot\frac46+20\cdot\frac36-15\cdot\frac26+6\cdot\frac16=5-10+10-5+1=1$. ✓ (при одном броске пять значений точно не появятся)
$n\to\infty$: все слагаемые стремятся к 0, вероятность → 0. ✓
Дополнение — вероятность увидеть все шесть граней («задача о собирателе купонов»).

### Задача 48. Бридж-рука без одной из мастей

Раздача 13 карт из 52. Пусть $A_i$ — «в руке нет карт масти $i$», $i=1,2,3,4$. Все руки равновероятны, всего $\binom{52}{13}$.

- $|A_i|=\binom{39}{13}$ — все 13 карт из трёх других мастей.
- $|A_i\cap A_j|=\binom{26}{13}$ — все карты из двух мастей.
- $|A_i\cap A_j\cap A_l|=\binom{13}{13}=1$ — вся рука одной масти.
- $|A_1\cap A_2\cap A_3\cap A_4|=0$ — 13 карт из ниоткуда не берутся.

$$P=\frac{\binom{4}{1}\binom{39}{13}-\binom{4}{2}\binom{26}{13}+\binom{4}{3}\binom{13}{13}}{\binom{52}{13}}
=\frac{4\binom{39}{13}-6\binom{26}{13}+4}{\binom{52}{13}}.$$

Числами: $\binom{39}{13}=8\,122\,425\,444$, $\binom{26}{13}=10\,400\,600$, $\binom{52}{13}=635\,013\,559\,600$.
$$P=\frac{32\,489\,701\,776-62\,403\,600+4}{635\,013\,559\,600}=\frac{32\,427\,298\,180}{635\,013\,559\,600}\approx\boxed{0.051}.$$

Примерно каждая двадцатая раздача — без какой-нибудь масти.

## 4. Что стоит запомнить

1. Четвёртая клетка — единственная, где деление на $k!$ ложно; там нужна биекция со «звёздами и полосками», и восстанавливать её надо через уравнение $x_1+\cdots+x_n=k$, $x_i\ge 0$.
2. $\binom{n+k-1}{k}$ считает **мультимножества**, а не равновероятные исходы. При выборе с возвращением сами мультимножества *не равновероятны* (см. задачу 21: набор $\{3,4,5\}$ и набор $\{3,3,4\}$ имеют разные ранги) — формула для подсчёта, но не для вероятностной модели.
3. Включение-исключение включается по сигналу «хоть бы одно из…» с симметричными событиями (задачи 47, 48). Проверяйте граничные слагаемые: часто последние обнуляются.
4. Дополнение (задача 2b) дешевле прямого подсчёта, когда запрет описывается короче, чем разрешение.
